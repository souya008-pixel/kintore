# 筋トレ計画 — 理想体型プランナー

身長・体重・目指す体型を入れると、理想の体型までの期間を計算し、
1週間ごとの筋トレメニュー（自重・ダンベル）と毎日の摂取カロリー・PFC、
そのカロリーに合わせた食事メニューの例（朝・昼・夜・間食）を表示する PWA です。

- 公開URL: https://souya008-pixel.github.io/kintore/
- スマホでは「ホーム画面に追加」するとアプリとして全画面で使えます
- データ（プロフィール・完了チェック・体重の記録）は端末の localStorage にだけ保存されます

## ファイル
- `index.html` … 画面とスタイル
- `app.js` … 体組成シミュレーション、メニュー生成、カロリー計算、描画
- `sw.js` / `manifest.webmanifest` … PWA（オフライン対応）。アセットを変えたら `sw.js` の `CACHE` 名を上げる
- `tools/make-icons.ps1` … アイコン生成（Windows PowerShell 5.1）

## 計算の概要
- 基礎代謝: 国立健康・栄養研究所の式。消費 = 基礎代謝 × 生活活動係数 + その日の運動
- 体脂肪率: 未入力なら Deurenberg の式で推定
- 減量期は体重の0.5〜0.75%/週、増量期は経験・年齢・性別に応じた筋肉の増加ペース
- 4週1ブロック（4週目はデロード）。ダンベルはブロックごとに約6%増、自重種目は8週ごとにレベルアップ
- 食事の例: 食品データ（成分表ベースの概算）と献立の型から、その日の kcal・たんぱく質・脂質に一番近い量の組み合わせを総当たりで選ぶ。日付ごとに決まった案が出て、「↻」で別の案に変えられる。自炊／コンビニ、食べられないもの（卵・乳製品・魚介・大豆・小麦）、プロテインの有無を設定できる
